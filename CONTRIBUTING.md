# Contribuir a HCC-PI Monitor

Gracias por contribuir a este proyecto académico open source. La colaboración debe preservar su carácter demostrativo, la privacidad y la distinción entre datos simulados y evidencia científica.

## Reportar problemas

Revise los issues existentes. Abra un issue con una descripción reproducible, entorno, pasos observados y resultado esperado. No adjunte historias clínicas, capturas con datos identificables ni secretos.

## Proponer funcionalidades o análisis

Use la plantilla de propuesta científica. Describa objetivo, utilidad académica, datos necesarios, riesgos de privacidad y validación propuesta. Identifique las hipótesis y no las presente como resultados.

## Flujo de trabajo

1. Haga un fork del repositorio.
2. Cree una rama descriptiva, por ejemplo `feature/mejora-calidad-datos`.
3. Realice cambios pequeños y documentados.
4. Ejecute la aplicación y verifique las páginas afectadas.
5. Envíe un pull request usando la plantilla incluida.

## Pull requests

Explique motivación, archivos modificados, verificaciones e impacto metodológico. Mantenga las dependencias al mínimo y no incluya `.venv`, credenciales ni datos personales.

## Integridad científica

Cualquier modificación de la definición de HCC-PI, sus variables, puntos de corte o metodología estadística debe identificarse explícitamente, justificarse científicamente, documentar su compatibilidad con resultados previos y actualizar metodología, diccionario y limitaciones. No presente hipótesis, simulaciones o funciones futuras como validaciones concluidas.

## Validaciones externas y colaboración multicéntrica

Se aceptan propuestas mediante issues. Cada iniciativa debe establecer su propio protocolo, aprobación ética, gobernanza, gestión de datos, criterios de elegibilidad y plan estadístico. Este repositorio no autoriza el intercambio de datos identificables.

Al contribuir, acepta que sus aportes se distribuyan bajo Apache License 2.0.
