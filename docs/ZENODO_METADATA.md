## Description

HCC-PI Monitor is an academic open source prototype for monitoring documented institutional adherence to five humanized childbirth practices. Demonstrative values are not clinical validation results, and the software is not intended for individual clinical decisions.

## Data availability

No individual-level research dataset is included in HCC-PI Monitor v1.0.0 or distributed through this software release. A future software deposit must exclude clinical datasets, secrets, local environments, and identifiable patient information.
